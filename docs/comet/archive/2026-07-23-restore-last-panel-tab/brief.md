# Outcome

插件面板因失焦关闭后，用户再次通过浏览器工具栏入口打开 DevGo 时恢复关闭前选中的功能页。

# Scope

- 持久化 popup 当前选中的“翻译”“待办”“网络”“资源”“功能”等功能页标识。
- 普通工具栏打开 popup 时恢复上次选中的有效功能页。
- 保留现有快捷键和后台一次性打开指定功能页的优先级。
- 在历史值缺失或无效时回退到现有默认功能页设置。

# Non-goals

- 不修改新标签页、选项页或其他页面的标签状态。
- 不修改默认功能页配置或快捷键定义。
- 不将该本机 popup 状态加入跨设备备份或同步。

# Acceptance examples

- 用户在 popup 中选择“待办”，点击浏览器空白处关闭面板，再点击工具栏 DevGo 图标，popup 显示“待办”。
- 用户在 popup 中选择“代码”等任意有效功能页后关闭并重新打开，显示关闭前选中的功能页。
- 快捷键或后台消息明确要求打开某个功能页时，popup 显示该指定页。
- 首次使用、历史记录不存在或历史功能页无效时，popup 显示“功能”页配置中的默认页。

# Constraints and invariants

- 状态使用现有 WXT local storage，保持在本机。
- 只接受已注册的 popup 功能页标识。
- 读取异步状态期间不得用默认页覆盖有效的已保存状态。

# Decisions

- 一次性快捷键打开信号优先于上次选中的功能页，维持当前快捷键语义。
- 默认功能页仅作为首次使用或无效历史记录的回退。

# Open questions

无。

# Verification expectations

- TypeScript 编译通过。
- 修改的 TypeScript 文件通过 ESLint 和 Prettier 检查。
- 人工验证 popup 关闭并重新打开后恢复“待办”页，以及快捷键指定页优先。
